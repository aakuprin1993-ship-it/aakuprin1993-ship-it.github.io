Политика конфиденциальности Assistent

Обновлено: 3 ноября 2026 г.

Assistent — личное приложение Александра Куприна (Telegram-бот на его собственном сервере). Им пользуется только владелец; другим пользователям приложение не предоставляется.

Какие данные Google использует приложение

  • Google Календарь — чтение, создание и изменение событий в календаре владельца.
  • Google Контакты — только чтение дней рождения из контактов владельца.
  • Gmail — работа с почтой владельца: чтение и поиск писем, краткая сводка непрочитанных и уведомления о срочных письмах, создание черновиков и ответов, отправка писем (только после подтверждения владельцем в Telegram), изменение меток (прочитано, архив, избранное). Безвозвратного удаления писем приложение не выполняет.

Как обрабатываются данные

  • Данные запрашиваются только по команде владельца или для его сводок и уведомлений и показываются только ему.
  • Чтобы составить сводку, ответ или черновик, текст нужных писем передаётся языковой модели (сервисы OpenRouter и DeepSeek) только для выполнения этого запроса.
  • Ключи доступа хранятся на сервере владельца; письма целиком не копируются и не хранятся вне Gmail, кроме сообщений, которые бот показал владельцу в Telegram.
  • Данные никому не продаются, не передаются для рекламы и не используются для обучения моделей.

Limited Use

Использование и передача информации, полученной из API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ можно отозвать в любой момент: myaccount.google.com/permissions → Assistent → «Удалить доступ».
